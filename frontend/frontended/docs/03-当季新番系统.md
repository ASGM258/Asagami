# 当季新番系统功能说明

## 📋 功能概述

当季新番系统展示当前季度的最新动漫，提供轮播图推荐、按星期分类浏览、数据刷新等功能。界面采用左右布局的轮播图和响应式网格列表，帮助用户快速发现热门新番。

---

## 🎯 核心功能

### 1. 轮播图推荐

**位置：** 页面顶部
**高度：** 520px
**自动播放：** 是（5秒间隔）

### 2. 按星期分类

**功能描述：**
- 显示周一至周日 + 待定共8个标签
- 默认选中当天（周一到周日映射为0-6）
- 点击标签切换显示的动漫列表

**星期映射：**
```typescript
// 前端显示
const weekDays = ['周一', '周二', '周三', '周四', '周五', '周六', '周日', '待定']

// 后端参数
// dayOfWeek: 1-7 对应周一到周日，8 表示待定
const backendParam = selectedDay.value === 7 ? 8 : (selectedDay.value + 1)
```

**UI 组件：**
```vue
<div class="day-tabs">
  <div 
    v-for="(day, index) in weekDays" 
    :key="index"
    class="day-tab"
    :class="{ active: selectedDay === index }"
    @click="selectDay(index)"
  >
    {{ day }}
  </div>
</div>
```

**选择逻辑：**
```typescript
const selectDay = (dayIndex: number) => {
  selectedDay.value = dayIndex
  // 转换为后端参数
  const backendParam = dayIndex === 7 ? 8 : (dayIndex + 1)
  fetchSeasonalAnime(backendParam)
}

// 初始化时选中当天
const selectedDay = ref<number>(
  new Date().getDay() === 0 ? 6 : new Date().getDay() - 1
)
// getDay(): 0=周日, 1=周一, ..., 6=周六
// 转换: 周日→6, 周一→0, 周二→1, ...
```

**API 接口：**
```typescript
GET /anime/seasonal?dayOfWeek=1
Response: {
  code: 200,
  data: SeasonalAnime[]
}

interface SeasonalAnime {
  mainId: number
  id?: number
  title: string
  coverImage: string
  episodes: number
  rating: number
  updateTime?: string  // 更新时间（格式: "HH:mm"）
}
```

### 3. 数据刷新功能

**功能描述：**
- 手动触发后端爬虫抓取最新数据
- 刷新成功后重新加载当前星期的数据
- 刷新失败统一提示"5分钟后刷新"

**UI 按钮：**
```vue
<el-button 
  type="primary" 
  size="small" 
  round
  :loading="refreshing"
  @click="handleRefreshSeasonal"
>
  <el-icon><Refresh /></el-icon>
  刷新
</el-button>
```

**刷新逻辑：**
```typescript
const handleRefreshSeasonal = async () => {
  try {
    refreshing.value = true
    
    const response = await refreshSeasonalAnime()
    
    if (response.code === 200) {
      ElMessage.success({
        message: response.data || '刷新成功',
        duration: 3000
      })
      // 重新获取当前选中的星期数据
      const backendParam = selectedDay.value === 7 ? 8 : (selectedDay.value + 1)
      await fetchSeasonalAnime(backendParam)
    } else {
      // 刷新失败，统一提示
      ElMessage.warning({
        message: '后端正在刷新数据，请5分钟后刷新新番页面',
        duration: 500000  // 显示5分钟
      })
    }
  } catch (error) {
    // 网络异常或超时，统一提示
    ElMessage.warning({
      message: '后端正在刷新数据，请5分钟后刷新新番页面',
      duration: 500000
    })
  } finally {
    refreshing.value = false
  }
}
```

**API 接口：**
```typescript
POST /anime/scraper/seasonal/refresh
Response: {
  code: 200,
  message: "刷新中",
  data: "已开始抓取数据，请稍后查看"
}
```

**设计考虑：**
- 爬虫抓取需要时间，不能立即返回最新数据
- 防止用户频繁点击刷新按钮
- 统一提示策略避免混淆

```typescript
const formatUpdateTime = (updateTime?: string): string => {
  if (!updateTime) return ''
  
  // 如果已经是格式化好的字符串，直接返回
  if (updateTime.includes(':')) {
    return updateTime
  }
  
  // 否则解析时间并格式化
  try {
    const date = new Date(updateTime)
    const hours = String(date.getHours()).padStart(2, '0')
    const minutes = String(date.getMinutes()).padStart(2, '0')
    return `${hours}:${minutes}`
  } catch {
    return updateTime
  }
}
```

### 图片加载优化

```vue
  :src="anime.coverImage" 
  loading="lazy"
  :class="{ 'loaded': imageLoaded[anime.mainId] }"
  @load="handleImageLoad(anime.mainId)"
  @error="handleImageError($event, anime.mainId)"
/>
```

### 文本截断

```typescript
const truncateText = (text: string, maxLength: number): string => {
  if (!text) return ''
  if (text.length <= maxLength) return text
  return text.substring(0, maxLength) + '...'
}
```

### 观看次数格式化

```typescript
const formatViews = (views: number): string => {
  if (views >= 10000) {
    return (views / 10000).toFixed(1) + 'w'  // 15234 → 1.5w
  }
  return views.toString()
}
```

## ⚡ 性能优化

### 已实施的优化

1. **懒加载图片** - `loading="lazy"`
2. **轮播图按需渲染** - 只渲染当前可见的幻灯片
3. **防抖刷新** - loading 状态防止重复点击
4. **条件渲染** - v-if 控制可选元素

### 优化建议

1. **预加载轮播图** - 提前加载下一张图片
2. **虚拟滚动** - 大量数据时使用
3. **图片压缩** - 使用 WebP 格式
4. **CDN 加速** - 静态资源 CDN
