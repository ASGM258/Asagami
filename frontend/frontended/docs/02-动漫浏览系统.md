# 动漫浏览系统功能说明

## 📋 功能概述

动漫浏览系统是应用的核心功能模块，提供动漫列表展示、分页加载、年份筛选、关键词搜索、观看状态标记等功能。采用响应式网格布局，支持多种设备尺寸。

---

## 🎯 核心功能

### 1. 动漫列表展示

**页面路径：** `/` (首页)

**功能描述：**
- 以卡片网格形式展示动漫列表
- 每页默认显示16个动漫（4×4布局）
- 支持自定义每页数量（16/32/48/64）
- 显示动漫封面、标题、集数、评分
- 懒加载图片优化性能

**卡片结构：**
```
┌─────────────────────┐
│                     │
│    封面图片          │
│   (3:4 比例)        │
│                     │
│  [评分] [状态图标]   │
├─────────────────────┤
│  动漫标题            │
│  XX 集              │
└─────────────────────┘
```

**API 接口：**
```typescript
GET /anime/list
Query Params: {
  pageNum: number,      // 页码（从1开始）
  pageSize: number,     // 每页数量
  title?: string,       // 搜索关键词（可选）
  year?: number         // 年份筛选（可选）
}
Response: {
  code: 200,
  message: "成功",
  data: {
    list: Anime[],
    total: number,      // 总记录数
    pageNum: number,    // 当前页码
    pageSize: number,   // 每页数量
    pages: number       // 总页数
  }
}
```

**Anime 类型定义：**
```typescript
interface Anime {
  id: number
  title: string
  coverImage: string
  episodes: number
  rating: number
  watchStatus?: number  // 0:未开始, 1:观看中, 2:已完成, 3:已放弃
  year?: number
  // ... 其他字段
}
```

### 2. 分页功能

**分页器配置：**
```vue
<el-pagination
  v-model:current-page="pagination.pageNum"
  v-model:page-size="pagination.pageSize"
  :total="pagination.total"
  :page-sizes="[16, 32, 48, 64]"
  layout="total, sizes, prev, pager, next, jumper"
  @size-change="handleSizeChange"
  @current-change="handlePageChange"
/>
```

**分页逻辑：**
```typescript
// 页码改变
const handlePageChange = (page: number) => {
  pagination.pageNum = page
  fetchAnimeList()
  window.scrollTo({ top: 0, behavior: 'smooth' })  // 滚动到顶部
}

// 每页数量改变
const handleSizeChange = (size: number) => {
  pagination.pageSize = size
  pagination.pageNum = 1  // 重置到第一页
  fetchAnimeList()
}
```

**后端分页实现：**
- 使用 PageHelper 插件
- SQL 自动添加 LIMIT 和 OFFSET
- 返回 PageInfo 对象包含分页信息

### 3. 年份筛选

**功能描述：**
- 生成年份选项：当前年份往前推20年 + "全部"选项
- 点击年份标签筛选对应年份的动漫
- 选中状态高亮显示

**年份选项生成：**
```typescript
const currentYear = new Date().getFullYear()
const yearOptions = Array.from({ length: 21 }, (_, i) => {
  const year = currentYear - i
  return { value: year, label: String(year) }
})
yearOptions.unshift({ value: null, label: '全部' })
```

**UI 组件：**
```vue
<el-tag 
  v-for="year in yearOptions" 
  :key="year.value"
  :type="selectedYear === year.value ? 'danger' : 'info'"
  :effect="selectedYear === year.value ? 'dark' : 'plain'"
  @click="handleYearChange(year.value)"
>
  {{ year.label }}
</el-tag>
```

**筛选逻辑：**
```typescript
const handleYearChange = (year: number | null) => {
  selectedYear.value = year
  pagination.pageNum = 1  // 重置到第一页
  fetchAnimeList()
}

// 构建查询参数
const queryParams: AnimeListQueryParams = {
  pageNum: pagination.pageNum,
  pageSize: pagination.pageSize
}

if (selectedYear.value !== null) {
  queryParams.year = selectedYear.value
}
```

### 4. 关键词搜索

**搜索入口：**
- Layout 组件顶部搜索框
- 通过 provide/inject 共享搜索状态

**搜索流程：**
```
用户输入 → Layout组件 → provide('searchQuery') → HomeView inject → 监听变化 → 调用API
```

**Layout 组件（提供者）：**
```vue
<script setup>
const searchQuery = ref('')
provide('searchQuery', searchQuery)

const handleSearch = () => {
  window.dispatchEvent(new CustomEvent('searchChange'))
}
</script>

<template>
  <el-input v-model="searchQuery" @keyup.enter="handleSearch" />
</template>
```

**HomeView 组件（消费者）：**
```vue
<script setup>
const searchQuery = inject<any>('searchQuery')

const fetchAnimeList = async () => {
  const queryParams = {
    pageNum: pagination.pageNum,
    pageSize: pagination.pageSize
  }
  
  if (searchQuery?.value && searchQuery.value.trim()) {
    queryParams.title = searchQuery.value.trim()
  }
  
  const response = await getAnimeList(queryParams)
  // ...
}

// 监听搜索变化事件
onMounted(() => {
  window.addEventListener('searchChange', handleSearchChange)
})

const handleSearchChange = () => {
  pagination.pageNum = 1
  fetchAnimeList()
}
</script>
```

**搜索特性：**
- 支持标题模糊匹配
- 实时搜索（按Enter或点击搜索按钮）
- 清空搜索后显示全部数据
- 搜索时重置到第一页

### 5. 观看状态标记

**功能描述：**
- 每个动漫卡片右上角显示爱心图标
- 点击图标弹出下拉菜单选择状态
- 四种状态：未开始、观看中、已完成、已放弃
- 不同状态显示不同颜色和样式

**状态定义：**
```typescript
enum WatchStatus {
  NOT_STARTED = 0,  // 未开始 - 空心白色爱心
  WATCHING = 1,     // 观看中 - 绿色实心爱心
  COMPLETED = 2,    // 已完成 - 红色实心爱心
  DROPPED = 3       // 已放弃 - 灰色实心爱心
}
```

**UI 实现：**
```vue

    <svg viewBox="0 0 1024 1024" width="24" height="24">
      <path d="M923 283.6c-13.4-31.1..."/>
    </svg>
  </div>
  <template #dropdown>
    <el-dropdown-menu>
      <el-dropdown-item :command="0">未开始</el-dropdown-item>
      <el-dropdown-item :command="1">观看中</el-dropdown-item>
      <el-dropdown-item :command="2">已完成</el-dropdown-item>
      <el-dropdown-item :command="3">已放弃</el-dropdown-item>
    </el-dropdown-menu>
  </template>
</el-dropdown>
```

**CSS 样式：**

**状态更新 API：**
```typescript
POST /anime/user-anime/update
Request: {
  animeId: number,
  watchStatus: number,        // 0-3
  currentEpisode?: number,    // 当前集数（可选）
  rating?: number,            // 评分（可选）
  comment?: string,           // 评论（可选）
  tags?: string[]             // 标签（可选）
}
Response: {
  code: 200,
  message: "更新成功"
}
```

**更新逻辑：**
```typescript
const handleWatchStatusChange = async (anime: Anime, status: number) => {
  try {
    const requestData: UpdateWatchStatusRequest = {
      animeId: anime.id,
      watchStatus: status,
      currentEpisode: undefined,
      rating: undefined,
      comment: undefined,
      tags: undefined
    }
    
    const response = await updateWatchStatus(requestData)
    
    if (response.code === 200) {
      // 更新本地状态
      anime.watchStatus = status
      
      // 显示成功消息
      const statusTextMap = {
        0: '未开始',
        1: '观看中',
        2: '已完成',
        3: '已放弃'
      }
      ElMessage.success(`已将《${anime.title}》标记为${statusTextMap[status]}`)
    }
  } catch (error) {
    ElMessage.error('更新观看状态失败')
  }
}
```

### 6. 图片优化

**懒加载：**
```vue
<img 
  :src="anime.coverImage" 
  loading="lazy"
  @load="handleImageLoad(anime.id)"
  @error="handleImageError($event, anime.id)"
/>
```

**加载状态跟踪：**
```typescript
const imageLoaded = reactive<Record<number, boolean>>({})

const handleImageLoad = (id: number) => {
  imageLoaded[id] = true
}

const handleImageError = (event: Event, id: number) => {
  const img = event.target as HTMLImageElement
  // 设置默认占位图（SVG base64）
  img.src = 'data:image/svg+xml;base64,PHN2ZyB3aWR0aD0iMzAwIiBoZWlnaHQ9IjQwMCI...'
  imageLoaded[id] = true
}
```

**透明度渐变动画：**
```scss
.cover-image {
  opacity: 0;
  transition: opacity 0.3s ease;
  
  &.loaded {
    opacity: 1;
  }
}
```

**占位符：**
```vue
<div v-if="!imageLoaded[anime.id]" class="image-placeholder">
  <el-icon :size="40" color="#909399"><Picture /></el-icon>
</div>
```

## 📊 数据流

```
用户操作（翻页/筛选/搜索）
   ↓
更新查询参数
   ↓
调用 getAnimeList API
   ↓
Axios 请求拦截器（添加 Token）
   ↓
Java 后端 (8081端口)
   ↓
PageHelper 分页查询
   ↓
返回 PageResponse<Anime>
   ↓
Axios 响应拦截器
   ↓
更新 animeList 和 pagination
   ↓
Vue 响应式更新 DOM
   ↓
图片懒加载
```

## 🔧 技术细节

### 查询参数构建

```typescript
interface AnimeListQueryParams {
  pageNum: number
  pageSize: number
  title?: string    // 搜索关键词
  year?: number     // 年份筛选
}

const queryParams: AnimeListQueryParams = {
  pageNum: pagination.pageNum,
  pageSize: pagination.pageSize
}

// 动态添加可选参数
if (searchQuery?.value?.trim()) {
  queryParams.title = searchQuery.value.trim()
}

if (selectedYear.value !== null) {
  queryParams.year = selectedYear.value
}
```

### 加载状态管理

```typescript
const loading = ref(false)

const fetchAnimeList = async () => {
  try {
    loading.value = true
    
    // 清空图片加载状态
    for (const key in imageLoaded) {
      delete imageLoaded[key]
    }
    
    const response = await getAnimeList(queryParams)
    
    if (response.code === 200) {
      animeList.value = response.data.list
      pagination.total = response.data.total
    }
  } finally {
    loading.value = false
  }
}
```

### 骨架屏加载

```vue
<div v-if="loading" class="loading-container">
  <el-skeleton :rows="4" animated />
</div>
```
