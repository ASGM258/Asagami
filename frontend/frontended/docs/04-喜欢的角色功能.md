# 喜欢的角色功能说明

## 📋 功能概述

"喜欢的角色"功能允许用户查看和管理自己收藏的喜爱角色列表。该功能参考观看历史页面的实现方式，提供分页浏览、搜索过滤、点击跳转详情等功能。

**页面路径：** `/favorite-characters`

---

## 🎯 核心功能

### 1. API 接口

**接口地址：** `GET /api/character/favorite/history`

**功能描述：** 分页查询用户喜欢的角色列表

**请求参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| pageNum | number | 否 | 页码（默认1） |
| pageSize | number | 否 | 每页数量（默认10） |
| name | string | 否 | 角色名称搜索（可选，支持模糊匹配） |

**认证要求：** 需要 JWT Token（必须登录）

**响应格式：**
```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "list": [
      {
        "id": 1,
        "malId": 40,
        "name": "日向雏田",
        "nameJp": "ヒナタ",
        "imageUrl": "https://example.com/hinata.jpg",
        "favorites": 15234,
        "isLiked": 1
      }
    ],
    "total": 25,
    "pageNum": 1,
    "pageSize": 12,
    "pages": 3
  },
  "timestamp": 1234567890
}
```

### 2. 核心特性

#### ✅ 联表查询
- 使用 `INNER JOIN` 连接 `user_favorite_character` 和 `anime_character` 表
- 确保只返回有效的角色数据

#### ✅ 状态过滤
- 只返回 `favorite_status = 1` 的记录
- 自动排除已取消喜欢的角色

#### ✅ 分页支持
- 使用 PageHelper 自动分页
- 支持自定义每页数量（12/24/36/48）

#### ✅ 名称搜索
- 支持英文名模糊匹配
- 支持日文名模糊匹配
- 实时搜索（按Enter或点击搜索按钮）

#### ✅ 缓存优化
- Redis 缓存 30 分钟
- 减少数据库查询压力

#### ✅ 按时间排序
- 最近喜欢的角色排在前面
- 方便用户快速找到新收藏的角色

#### ✅ 完整信息
- 返回角色ID、MAL ID
- 中英文名称
- 头像URL
- 受欢迎程度
- 喜欢状态

### 4. 技术实现

#### API 调用

```typescript
// api/anime.ts
export const getFavoriteCharacterList = (params: CharacterListQueryParams): Promise<ApiResponse<PageResponse<Character>>> => {
  return api.get('/character/favorite/history', { params })
}
```

#### 组件实现

```vue
<script setup lang="ts">
import { ref, onMounted, reactive } from 'vue'
import { useRouter } from 'vue-router'
import { getFavoriteCharacterList, updateCharacterFavorite } from '@/api/anime'
import { useAuthStore } from '@/stores/auth'

const router = useRouter()
const authStore = useAuthStore()

const characterList = ref<Character[]>([])
const loading = ref(false)
const searchName = ref('')

const pagination = reactive({
  pageNum: 1,
  pageSize: 12,
  total: 0
})

// 获取喜欢的角色列表
const fetchFavoriteCharacterList = async () => {
  try {
    loading.value = true
    
    const params: CharacterListQueryParams = {
      pageNum: pagination.pageNum,
      pageSize: pagination.pageSize
    }
    
    if (searchName.value.trim()) {
      params.name = searchName.value.trim()
    }
    
    const response = await getFavoriteCharacterList(params)
    
    if (response.code === 200 && response.data) {
      const pageInfo = response.data as any
      characterList.value = pageInfo.list || []
      pagination.total = pageInfo.total || 0
    }
  } finally {
    loading.value = false
  }
}

// 跳转到角色详情页
const goToDetail = (characterId: number) => {
  router.push(`/characters/${characterId}`)
}

// 取消喜欢
const toggleLike = async (character: Character) => {
  const response = await updateCharacterFavorite({
    characterId: character.id,
    favoriteStatus: 0  // 取消喜欢
  })
  
  if (response.code === 200) {
    ElMessage.success('已取消喜欢')
    await fetchFavoriteCharacterList()  // 重新加载列表
  }
}

onMounted(() => {
  if (!authStore.isLoggedIn) {
    ElMessage.warning('请先登录')
    router.push('/login')
    return
  }
  fetchFavoriteCharacterList()
})
</script>
```

## 🔄 数据流

```
用户访问 /favorite-characters
   ↓
检查登录状态
   ↓
调用 getFavoriteCharacterList API
   ↓
Axios 添加 Authorization Header
   ↓
Java 后端 (8081端口)
   ↓
查询 user_favorite_character 表（favorite_status=1）
   ↓
INNER JOIN anime_character 表
   ↓
PageHelper 分页
   ↓
Redis 缓存（30分钟）
   ↓
返回 PageResponse<Character>
   ↓
前端渲染角色卡片网格
   ↓
用户点击卡片
   ↓
跳转到 /characters/:id 详情页
```

## ⚡ 性能优化

### 已实施的优化

1. **图片懒加载** - `loading="lazy"`
2. **分页加载** - 避免一次性加载大量数据
3. **Redis 缓存** - 30分钟缓存减少数据库压力
4. **防抖搜索** - 避免频繁请求
5. **条件渲染** - v-if 控制可选元素

### 优化建议

1. **虚拟滚动** - 大量数据时使用
2. **图片CDN** - 加速图片加载
3. **预加载** - 预测用户行为，预加载下一页
4. **骨架屏** - 替换简单的 loading 状态

## 🔐 安全考虑

### 认证要求

- 必须登录才能访问
- 路由守卫自动拦截未登录用户
- API 请求携带 JWT Token

### 数据隔离

- 每个用户只能看到自己的喜欢列表
- 后端通过 userId 过滤数据
- 防止越权访问其他用户数据
