# 翻译工具功能说明

## 📖 概述

翻译工具是一个独立的Python脚本，用于批量翻译数据库中的动漫和角色信息。它利用DeepSeek API将英文内容翻译成中文，支持多种字段类型和翻译模式。

## ✨ 核心特性

### 1. 多字段支持
- **动漫标题**: title（如 "Attack on Titan" → "进击的巨人"）
- **动漫简介**: synopsis（长篇文本翻译）
- **动漫体裁**: genres（标签翻译，如 "Action, Adventure" → "动作, 冒险"）
- **角色名称**: name（角色名翻译）
- **角色简介**: about（角色背景故事翻译）
- **角色昵称**: nicknames（别名/绰号翻译）

### 2. 智能翻译
- **上下文感知**: 针对不同字段使用不同的prompt模板
- **差异化配置**: 根据文本长度调整max_tokens参数
- **截断检测**: 自动检测API返回是否被截断
- **中文跳过**: 已包含中文的内容自动跳过

### 3. 安全机制
- **NULL值处理**: 跳过NULL字段避免错误
- **速率控制**: 每次请求间隔1秒，避免API限流
- **错误恢复**: 单条失败不影响整体流程
- **事务安全**: 每条更新独立提交

### 2. 核心函数

#### translate_with_deepseek()

位置: `translate/translate_anime_titles.py`

**功能**: 调用DeepSeek API进行翻译

**参数**:
- `text`: 需要翻译的文本
- `mode`: 翻译模式（'title', 'synopsis', 'genres', 'character_name', 'character_about', 'character_nicknames'）
- `field_type`: 字段类型标识

**实现逻辑**:

```python
def translate_with_deepseek(text, mode='title', field_type='title'):
    # 1. 根据模式构建prompt
    if mode == 'title':
        prompt = f"""请将以下动漫名称翻译成准确的中文译名。要求：
1. 只返回翻译结果，不要有任何解释或额外文字
2. 如果已经是中文，保持原样
3. 如果是知名动漫，使用官方或广泛认可的中文译名
...
需要翻译的名称：{text}"""
    
    elif mode == 'synopsis':
        prompt = f"""请将以下动漫简介翻译成流畅自然的中文。要求：
1. 保持原文的意思和情感色彩
2. 使用通顺、地道的中文表达
...
需要翻译的简介：{text}"""
    
    # ... 其他模式
    
    # 2. 配置差异化参数
    if mode in ['synopsis', 'character_about']:
        max_tokens = 8000  # 简介需要更多token
        system_prompt = '你是一个专业的动漫简介翻译助手...'
    elif mode in ['character_nicknames']:
        max_tokens = 500   # 昵称中等长度
        system_prompt = '你是一个专业的动漫角色昵称翻译助手...'
    else:
        max_tokens = 200   # 标题/体裁/角色名较短
        system_prompt = '你是一个专业的动漫名称翻译助手...'
    
    # 3. 调用API
    data = {
        'model': 'deepseek-chat',
        'messages': [
            {'role': 'system', 'content': system_prompt},
            {'role': 'user', 'content': prompt}
        ],
        'temperature': 0.3,  # 较低温度保证翻译准确性
        'max_tokens': max_tokens
    }
    
    response = requests.post(DEEPSEEK_API_URL, headers=headers, json=data, timeout=60)
    result = response.json()
    translated_text = result['choices'][0]['message']['content'].strip()
    
    # 4. 检测截断
    finish_reason = result['choices'][0].get('finish_reason', '')
    if finish_reason == 'length':
        print(f"\n⚠️ 警告: API返回被截断 (max_tokens={max_tokens})")
    
    # 5. 清理结果
    translated_text = translated_text.strip('\"\'').strip()
    
    return translated_text
```

**关键设计点**:

1. **Prompt工程**: 每个模式都有专门的指令，确保翻译质量
2. **Token优化**: 
   - 标题/角色名: 200 tokens（简短精确）
   - 昵称: 500 tokens（中等长度）
   - 简介: 8000 tokens（长文本）
3. **Temperature设置**: 0.3（低创造性，高准确性）
4. **超时控制**: 60秒超时避免长时间等待

def get_anime_list(connection, field='title', table='anime'):
    cursor = connection.cursor(dictionary=True)
    
    query = f"""

        ORDER BY id
    """

    cursor.close()
    
    return results

#### is_chinese()

**功能**: 检测文本是否包含中文字符

```python
def is_chinese(text):
    """检查文本是否包含中文字符"""
    for char in text:
        if '\u4e00' <= char <= '\u9fff':  # Unicode中文范围
            return True
    return False
```

**Unicode范围**: `\u4e00` - `\u9fff` 覆盖常用汉字

#### update_field()

**功能**: 更新数据库记录

```python
def update_field(connection, record_id, new_value, field='title', table='anime'):
    cursor = connection.cursor()
    
    query = f"UPDATE {table} SET {field} = %s WHERE id = %s"
    cursor.execute(query, (new_value, record_id))
    connection.commit()
    
    cursor.close()
    return True
```

**安全措施**:
- 使用参数化查询防止SQL注入
- 立即提交保证数据持久化
- 独立事务避免批量失败

#### 错误: 数据库连接失败

**症状**:
```
连接数据库失败: Access denied for user 'root'@'localhost'

**症状**:

**原因**:
- API返回异常
- 响应解析失败

**解决**:
- 查看完整错误日志
- 检查API配额
- 手动测试API调用

**症状**:
```

**原因**:
- 文本过长超出max_tokens限制

**解决**:
- 增加对应模式的max_tokens值
- 分段翻译长文本
- 接受部分翻译结果

## 📈 性能优化

### 1. 批量处理策略

**当前方式**: 逐条处理（串行）

**优点**:
- 简单可靠
- 易于错误处理
- 实时看到进度

**缺点**:
- 速度较慢（150条约需150秒）

**改进方案**: 批量并发

```python
from concurrent.futures import ThreadPoolExecutor

def batch_translate(records, max_workers=5):
    with ThreadPoolExecutor(max_workers=max_workers) as executor:
        futures = [executor.submit(translate_single, record) for record in records]
        for future in as_completed(futures):
            process_result(future.result())
```

**注意**: 并发需考虑API限流

def translate_with_cache(text, mode):
