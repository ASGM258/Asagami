## 🛠️ API 接口索引

### 认证接口 `/api/auth`
- `POST /register` - 用户注册
- `POST /login` - 用户登录
- `GET /profile` - 获取用户信息
- `PUT /profile` - 更新用户信息

[详细文档](./01-用户认证与授权功能.md)

### 动漫接口 `/api/anime`
- `GET /list` - 分页查询动漫
- `POST /detail` - 获取动漫详情
- `GET /seasonal` - 查询当季新番
- `GET /banners` - 获取轮播图
- `PUT /user/update` - 更新追番状态
- `GET /user/history` - 查询追番历史

[详细文档](./02-动漫数据管理功能.md)

### 角色接口 `/api/character`
- `GET /list` - 分页查询角色
- `POST /detail` - 获取角色详情
- `POST /favorite/update` - 更新喜欢状态

[详细文档](./03-角色管理功能.md)

### 评论接口 `/api/comment`
- `POST /add` - 发表评论
- `PUT /update` - 更新评论
- `DELETE /delete/{commentId}` - 删除评论
- `GET /list/{animeId}` - 查询评论列表
- `POST /reply/add` - 发表回复
- `DELETE /reply/delete/{replyId}` - 删除回复
- `POST /like` - 点赞/取消点赞
- `GET /like/status/{animeId}` - 查询点赞状态

[详细文档](./04-评论系统功能.md)

### 文件上传接口 `/api/upload`
- `POST /image` - 上传图片
- `POST /avatar` - 上传头像
- `POST /cover` - 上传封面
- `DELETE /file` - 删除文件

[详细文档](./06-文件上传功能.md)

### 爬虫接口 `/anime/scraper`
- `POST /fetch/{malId}` - 抓取单个动漫
- `POST /fetch/batch` - 批量抓取动漫

[详细文档](./05-爬虫与数据同步功能.md)

### 当季新番接口 `/api/anime/scraper/seasonal`
- `POST /fetch` - 抓取当季新番
- `POST /refresh` - 刷新当季新番
- `POST /smart-update` - 智能更新

[详细文档](./05-爬虫与数据同步功能.md)

### 管理接口 `/api/admin`
- `POST /cache/clear-all` - 清除所有缓存

[详细文档](./07-缓存管理功能.md)
