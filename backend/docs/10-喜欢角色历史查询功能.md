# 喜欢角色历史查询功能说明

## 📋 功能概述

本功能允许用户查询自己喜欢的所有角色列表，支持分页查询和按角色名称搜索。只返回 `favorite_status=1`（喜欢）的角色记录，并包含完整的角色信息和喜欢状态。

## 🔧 技术实现

### 核心组件
- **Controller**: `UserFavoriteCharacterController`
- **Service**: `CharacterQueryService`, `CharacterQueryServiceImpl`
- **Mapper**: `CharacterMapper`, `CharacterMapper.xml`
- **缓存**: Redis缓存（30分钟过期）

### 架构设计
```
客户端 → UserFavoriteCharacterController → CharacterQueryService → CharacterMapper → Database
                                                    ↓
                                              CacheService
                                                    ↓
                                                  Redis
```

## 📡 API 接口详情

### 查询用户喜欢角色历史

**接口地址**: `GET /api/character/favorite/history`

**请求头**:
```
Authorization: Bearer <token>
```

**请求参数**:
```
pageNum: 1              // 页码，默认1
pageSize: 10            // 每页数量，默认10
name: "艾伦"            // 角色名称搜索关键词（可选，支持模糊匹配）
```

**响应示例**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 25,
    "pageNum": 1,
    "pageSize": 10,
    "pages": 3,
    "list": [
      {
        "id": 1,
        "malId": 40882,
        "name": "Eren Yeager",
        "nameJp": "エレン・イェーガー",
        "imageUrl": "https://cdn.myanimelist.net/images/characters/10/216895.jpg",
        "favorites": 150000,
        "isLiked": 1
      },
      {
        "id": 2,
        "malId": 40881,
        "name": "Mikasa Ackerman",
        "nameJp": "ミカサ・アッカーマン",
        "imageUrl": "https://cdn.myanimelist.net/images/characters/9/215563.jpg",
        "favorites": 120000,
        "isLiked": 1
      }
    ]
  }
}
```

**业务逻辑**:
1. 验证用户登录状态（必须登录）
2. 生成缓存键（包含用户ID、分页参数、搜索关键词）
3. 尝试从Redis获取缓存
4. 缓存未命中时查询数据库
   - INNER JOIN `user_favorite_character` 和 `anime_character`
   - 过滤条件：`user_id = #{userId}` AND `favorite_status = 1`
   - 支持按角色名称模糊搜索（英文名或日文名）
   - 按更新时间倒序排列（最近喜欢的在前）
5. 转换为DTO（`isLiked` 始终为 1）
6. 设置缓存并返回结果

**缓存策略**:
- 缓存键格式：`anime:manager:user:favorite-character:{userId}:{pageNum}:{pageSize}:{name}`
- 过期时间：30分钟
- 清除时机：更新喜欢状态后清除该用户的所有喜欢历史缓存

**错误码**:
- `401` - 未登录
- `500` - 系统错误

## 🗄️ 数据库查询

### SQL 查询逻辑

```xml
<select id="findUserFavoriteCharacterHistory" resultMap="CharacterResultMap">
    SELECT 
        ac.id, 
        ac.mal_id, 
        ac.name, 
        ac.name_jp, 
        ac.image_url, 
        ac.favorites,
        ufc.favorite_status AS isLiked,
        ufc.updated_at AS updatedAt
    FROM user_favorite_character ufc
    INNER JOIN anime_character ac ON ufc.character_id = ac.id
    WHERE ufc.user_id = #{userId}
      AND ufc.favorite_status = 1
    <if test="name != null and name != ''">
        AND (ac.name LIKE CONCAT('%', #{name}, '%') OR ac.name_jp LIKE CONCAT('%', #{name}, '%'))
    </if>
    ORDER BY ufc.updated_at DESC
</select>
```

**查询特点**:
- 使用 `INNER JOIN` 确保只返回存在的角色
- 过滤 `favorite_status = 1` 确保只返回喜欢的角色
- 支持中英文/日文名称模糊匹配
- 按更新时间倒序，最近喜欢的角色排在前面
- 返回 `updated_at` 字段可用于前端显示"喜欢时间"

## ⚠️ 注意事项

### 安全性

1. **必须登录**
   - 接口需要 JWT Token 认证
   - 未登录用户无法访问
   - 从 UserContext 获取当前用户 ID

2. **数据隔离**
   - 每个用户只能查看自己的喜欢记录
   - 通过 `user_id` 严格过滤
   - 防止越权访问

### 性能优化

1. **分页查询**
   - 使用 PageHelper 自动分页
   - 避免一次性加载大量数据
   - 默认每页 10 条

2. **缓存策略**
   - Redis 缓存 30 分钟
   - 减少数据库查询
   - 提升响应速度

3. **索引优化**
   - `user_favorite_character.user_id` 索引
   - `user_favorite_character.character_id` 索引
   - `user_favorite_character.favorite_status` 索引
   - `anime_character.name` 前缀索引
   - `anime_character.name_jp` 前缀索引

### 数据一致性

1. **缓存同步**
   - 更新喜欢状态后立即清除缓存
   - 使用通配符删除所有相关缓存
   - 保证下次查询获取最新数据

2. **联表查询**
   - 使用 INNER JOIN 确保数据完整性
   - 只返回存在的角色
   - 避免孤儿记录

## 📝 常见问题

### Q1: 为什么只返回 favorite_status=1 的记录？

**A**: 
- 该接口的目的是展示用户"喜欢"的角色
- `favorite_status=0` 表示取消喜欢，不应出现在喜欢列表中
- 保持数据语义清晰

### Q2: 如何实现按喜欢时间排序？

**A**: 
- 当前已按 `ufc.updated_at DESC` 排序
- 最近喜欢/更新的角色排在前面
- 可根据需求改为 `ufc.created_at DESC`（首次喜欢时间）

### Q3: 缓存何时失效？

**A**: 
- 自然过期：30分钟后
- 主动清除：用户更新喜欢状态时
- 手动清除：管理员清除所有缓存时

### Q4: 如何统计用户喜欢的角色总数？

**A**: 
```sql
SELECT COUNT(*) FROM user_favorite_character 
WHERE user_id = #{userId} AND favorite_status = 1;
```
可在 Service 层添加统计方法。

### Q5: 支持导出喜欢列表吗？

**A**: 
- 当前不支持
- 可扩展为 CSV/Excel 导出功能
- 遍历所有分页数据即可

## 🎯 使用示例

### cURL 示例

```bash
# 查询第一页
curl -X GET "http://localhost:8081/api/character/favorite/history?pageNum=1&pageSize=10" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# 搜索特定角色
curl -X GET "http://localhost:8081/api/character/favorite/history?pageNum=1&pageSize=10&name=艾伦" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### JavaScript 示例

```javascript
// 使用 fetch API
async function getFavoriteCharacters(pageNum = 1, pageSize = 10, name = '') {
  const params = new URLSearchParams({
    pageNum,
    pageSize,
    ...(name && { name })
  });
  
  const response = await fetch(
    `/api/character/favorite/history?${params}`,
    {
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('token')}`
      }
    }
  );
  
  const result = await response.json();
  return result.data;
}

// 使用示例
const favorites = await getFavoriteCharacters(1, 10, '艾伦');
console.log(`总共 ${favorites.total} 个喜欢的角色`);
favorites.list.forEach(char => {
  console.log(`${char.name} (${char.nameJp})`);
});
```
