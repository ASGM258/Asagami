# 动漫管理网站 - 项目说明文档

## 📖 项目概述

**动漫管理网站**是一个基于 Spring Boot 4.0 构建的全栈后端系统，提供完整的动漫数据管理、用户互动社区、智能爬虫数据采集等功能。系统采用现代化的技术架构，集成了 JWT 认证、Redis 缓存、阿里云 OSS 文件存储等企业级特性，为用户提供流畅的动漫管理和社交体验。

### 项目定位

- **目标用户**: 动漫爱好者、二次元文化爱好者
- **核心价值**: 
  - 一站式动漫信息管理
  - 活跃的社区互动平台
  - 智能化的数据同步
  - 个性化的追番体验

### 主要特性

✅ **完整的用户系统** - 注册、登录、个人信息管理  
✅ **丰富的动漫数据** - 自动抓取 MyAnimeList 数据  
✅ **智能当季新番** - 定时更新当前季度热门动漫  
✅ **活跃的评论社区** - 多级评论、点赞互动  
✅ **个性化追番** - 多种观看状态、进度追踪  
✅ **角色收藏** - 喜欢的角色一键收藏  
✅ **高性能缓存** - Redis 缓存提升响应速度  
✅ **文件上传** - 阿里云 OSS 存储图片资源  
✅ **轮播图推荐** - 智能展示热门动漫

### 分层架构

#### 1. Controller 层（控制器层）
- **职责**: 接收 HTTP 请求，参数校验，调用 Service 层
- **位置**: `com.anime.manager.controller`
- **特点**: 
  - RESTful API 设计
  - 统一返回格式 `Result<T>`
  - 异常统一处理

#### 2. Service 层（业务逻辑层）
- **职责**: 业务逻辑处理，事务管理，缓存操作
- **位置**: `com.anime.manager.service`
- **特点**:
  - 接口与实现分离
  - 声明式事务管理
  - 缓存策略实施

#### 3. Mapper 层（数据访问层）
- **职责**: 数据库 CRUD 操作
- **位置**: `com.anime.manager.mapper` + `src/main/resources/mapper`
- **特点**:
  - MyBatis XML 动态 SQL
  - 联表查询优化
  - 批量操作支持

#### 4. Entity 层（实体层）
- **职责**: 数据库表映射
- **位置**: `com.anime.manager.entity`
- **特点**:
  - Lombok 简化代码
  - Builder 模式
  - 字段注释完整

#### 5. DTO/VO 层（数据传输层）
- **DTO**: 接收客户端请求参数
- **VO**: 封装返回给客户端的数据
- **特点**: 解耦数据库结构与 API 结构

## 🔧 核心模块说明

### 1. 用户认证模块
- **功能**: 用户注册、登录、信息管理
- **技术**: JWT + BCrypt + Spring Security
- **特点**: 单 Token 机制，密码加密存储

### 2. 动漫数据模块
- **功能**: 动漫查询、详情展示、追番管理
- **技术**: MyBatis + PageHelper + Redis
- **特点**: 多语言标题支持，中文映射，分页缓存

### 3. 角色管理模块
- **功能**: 角色查询、详情展示、收藏管理
- **技术**: MyBatis + Redis
- **特点**: 联表查询喜欢状态，批量点赞查询

### 4. 评论系统模块
- **功能**: 发表评论、回复、点赞、删除
- **技术**: MyBatis + 事务管理
- **特点**: 两级回复结构，批量点赞状态查询，权限验证

### 5. 爬虫同步模块
- **功能**: 动漫抓取、角色抓取、当季新番同步
- **技术**: RestTemplate + AniList GraphQL + Spring Scheduler
- **特点**: 速率限制处理，异常分类，智能更新策略

### 6. 文件上传模块
- **功能**: 头像、封面、普通图片上传
- **技术**: 阿里云 OSS SDK
- **特点**: 文件类型验证，大小限制，自动更新数据库

### 7. 缓存管理模块
- **功能**: 数据缓存、缓存清除、缓存键管理
- **技术**: Spring Data Redis + Jackson
- **特点**: 多维度缓存键，通配符清除，Java 8 日期支持

### 8. 轮播图模块
- **功能**: 随机展示热门动漫
- **技术**: MyBatis + Redis
- **特点**: 按热门程度排序，缓存优化

## 🗄️ 数据库设计总览

### 核心数据表（14张）

| 表名 | 说明 | 记录数估算 |
|------|------|-----------|
| user | 用户表 | 根据用户量 |
| anime | 动漫主表 | 10,000+ |
| anime_name_mapping | 动漫名称映射表 | 10,000+ |
| anime_schedule | 当季新番排期表 | 每季 ~100 |
| character | 角色表 | 50,000+ |
| anime_comment | 动漫评论表 | 根据活跃度 |
| comment_reply | 评论回复表 | 根据活跃度 |
| character_comment | 角色评论表 | 根据活跃度 |
| character_comment_reply | 角色评论回复表 | 根据活跃度 |
| user_comment_like | 用户评论点赞表 | 根据活跃度 |
| character_comment_like | 角色评论点赞表 | 根据活跃度 |
| user_anime | 用户追番表 | 根据用户行为 |
| watch_history | 观看历史表 | 根据用户行为 |
| user_favorite_character | 用户喜欢角色表 | 根据用户行为 |

### 索引策略

- **主键索引**: 所有表的 id 字段
- **唯一索引**: 防止重复数据（用户名、邮箱、MAL ID 等）
- **普通索引**: 查询频繁的字段（user_id, anime_id, create_time 等）
- **前缀索引**: 长文本字段（title(100), name(100) 等）

## 🚀 部署指南

### 前置要求

- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Redis 6.0+
- 阿里云 OSS 账号

### 部署步骤

1. **准备环境**
   ```bash
   # 安装 JDK 17
   java -version
   
   # 安装 Maven
   mvn -version
   
   # 启动 MySQL
   mysql --version
   
   # 启动 Redis
   redis-cli ping
   ```

2. **配置数据库**
   ```sql
   CREATE DATABASE backend_asagami CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   USE backend_asagami;
   -- 执行建表脚本
   ```

3. **配置环境变量**
   ```bash
   cp .env.example .env
   # 编辑 .env 文件，填入实际配置
   ```

4. **编译打包**
   ```bash
   mvn clean package -DskipTests
   ```

5. **启动应用**
   ```bash
   java -jar target/backend-0.0.1-SNAPSHOT.jar
   ```

6. **验证服务**
   ```bash
   curl http://localhost:8081/api/anime/list
   ```

### Docker 部署（可选）

```dockerfile
FROM openjdk:17-jdk-slim
WORKDIR /app
COPY target/backend-0.0.1-SNAPSHOT.jar app.jar
EXPOSE 8081
ENTRYPOINT ["java", "-jar", "app.jar"]
```

## 📊 性能指标

### 预期性能

- **API 响应时间**: < 200ms（缓存命中）
- **API 响应时间**: < 500ms（数据库查询）
- **并发支持**: 1000+ QPS
- **数据库连接池**: 最大 8 个连接
- **Redis 内存使用**: < 2GB

### 优化建议

1. **数据库优化**
   - 合理使用索引
   - 避免 N+1 查询
   - 定期分析慢查询日志

2. **缓存优化**
   - 热点数据预加载
   - 合理设置过期时间
   - 监控缓存命中率

3. **代码优化**
   - 异步处理耗时操作
   - 批量查询代替循环查询
   - 减少对象创建
