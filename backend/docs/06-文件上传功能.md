# 文件上传功能文档

## 📋 功能概述

本模块提供基于阿里云 OSS（对象存储服务）的文件上传功能，支持图片、头像、封面等文件的上传和删除。集成用户认证，自动更新用户头像信息到数据库，并提供文件类型和大小的验证。

## 🔧 技术实现

### 核心技术栈
- **阿里云 OSS SDK 3.17.4** - 对象存储客户端
- **Spring Multipart** - 文件上传处理
- **Jakarta Validation** - 文件验证
- **UserContext** - 用户身份获取

### 架构设计
```
客户端 → FileUploadController → AliyunOssUtil → 阿里云 OSS
                                    ↓
                              UserMapper (更新头像)
                                    ↓
                                 Database
```

## 📡 API 接口详情

### 1. 上传图片

**接口地址**: `POST /api/upload/image`

**请求头**:
```
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求参数**:
```
file: [Binary Image File]    // 图片文件，表单字段名 "file"
```

**响应示例**:
```json
{
  "code": 200,
  "message": "上传成功",
  "data": "https://web-sky-dwk.oss-cn-beijing.aliyuncs.com/images/2026/07/09/abc123.jpg"
}
```

**业务逻辑**:
1. 验证文件类型（必须是图片）
2. 验证文件大小（不超过 5MB）
3. 生成唯一文件名（UUID + 日期路径）
4. 上传到阿里云 OSS（images/日期/ 目录）
5. 返回文件 URL

**文件验证**:
- 类型：image/jpeg, image/png, image/gif, image/webp 等
- 大小：最大 5MB

**存储路径**:
```
images/2026/07/09/{uuid}.jpg
```

**错误码**:
- `400` - 文件类型不支持
- `400` - 文件大小超限
- `500` - 上传失败

### 2. 上传头像

**接口地址**: `POST /api/upload/avatar`

**请求头**:
```
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

**请求参数**:
```
avatar: [Binary Image File]  // 头像文件，表单字段名 "avatar"
```

**响应示例**:
```json
{
  "code": 200,
  "message": "上传成功",
  "data": "https://web-sky-dwk.oss-cn-beijing.aliyuncs.com/avatars/2026/07/09/xyz456.jpg"
}
```

**业务逻辑**:
1. 验证文件类型（必须是图片）
2. 验证文件大小（不超过 2MB）
3. 生成唯一文件名
4. 上传到阿里云 OSS（avatars/ 目录）
5. **自动更新数据库中的用户头像 URL**
6. 返回文件 URL

**特殊处理**:
- 上传成功后自动调用 `userMapper.updateAvatar(userId, url)`
- 从请求中获取当前用户 ID
- 立即更新数据库记录

**文件验证**:
- 类型：image/jpeg, image/png, image/gif, image/webp 等
- 大小：最大 2MB（比一般图片更严格）

**存储路径**:
```
avatars/2026/07/09/{uuid}.jpg
```

**错误码**:
- `401` - 未登录
- `400` - 文件类型不支持
- `400` - 文件大小超限
- `500` - 上传失败或数据库更新失败

## ⚙️ 阿里云 OSS 配置

### application.yaml 配置

```yaml
aliyun:
  oss:
    # Endpoint（地域节点）
    endpoint: ${OSS_ENDPOINT:oss-cn-beijing.aliyuncs.com}
    # AccessKey 只能通过环境变量注入，不要在配置文件里写默认值
    access-key-id: ${OSS_ACCESS_KEY_ID:}
    access-key-secret: ${OSS_ACCESS_KEY_SECRET:}
    # Bucket名称
    bucket-name: ${OSS_BUCKET_NAME:web-sky-dwk}
```

### 环境变量配置

在 `.env` 文件中配置敏感信息：
```properties
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
OSS_ACCESS_KEY_ID=your_access_key_id
OSS_ACCESS_KEY_SECRET=your_access_key_secret
OSS_BUCKET_NAME=your_bucket_name
```

**安全建议**:
- 生产环境必须使用环境变量
- 不要将 AccessKey 提交到版本控制系统
- 定期更换 AccessKey
- 使用 RAM 子账号限制权限

## 🔧 AliyunOssUtil 工具类

### 核心方法

#### 1. 上传文件（默认目录）

```java
public String uploadFile(MultipartFile file) {
    return uploadFile(file, "images");
}
```

#### 2. 上传文件（指定目录）

```java
public String uploadFile(MultipartFile file, String directory) {
    try {
        // 1. 生成文件名
        String originalFilename = file.getOriginalFilename();
        String extension = getFileExtension(originalFilename);
        String fileName = UUID.randomUUID().toString() + "." + extension;
        
        // 2. 构建 OSS Key
        String datePath = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
        String key = directory + "/" + datePath + "/" + fileName;
        
        // 3. 上传到 OSS
        ossClient.putObject(bucketName, key, file.getInputStream());
        
        // 4. 返回访问 URL
        return "https://" + bucketName + "." + endpoint + "/" + key;
        
    } catch (Exception e) {
        log.error("文件上传失败: {}", e.getMessage(), e);
        throw new BusinessException("文件上传失败: " + e.getMessage());
    }
}
```

#### 3. 删除文件

```java
public void deleteFile(String fileUrl) {
    try {
        // 1. 从 URL 提取 Key
        String key = extractKeyFromUrl(fileUrl);
        
        // 2. 删除 OSS 对象
        ossClient.deleteObject(bucketName, key);
        
        log.info("文件删除成功: {}", fileUrl);
        
    } catch (Exception e) {
        log.error("文件删除失败: {}", e.getMessage(), e);
        throw new BusinessException("文件删除失败: " + e.getMessage());
    }
}
```

#### 4. 文件扩展名提取

```java
private String getFileExtension(String filename) {
    if (filename == null || filename.isEmpty()) {
        throw new BusinessException("文件名不能为空");
    }
    
    int lastDotIndex = filename.lastIndexOf(".");
    if (lastDotIndex == -1) {
        throw new BusinessException("文件没有扩展名");
    }
    
    return filename.substring(lastDotIndex + 1).toLowerCase();
}
```

## ⚠️ 注意事项

### 性能优化

1. **异步上传**
   - 大文件可异步上传
   - 返回上传任务 ID
   - 前端轮询上传状态

2. **CDN 加速**
   - OSS 绑定 CDN 域名
   - 提升访问速度
   - 降低 OSS 流量成本

3. **图片压缩**
   - 上传前前端压缩
   - 或使用 OSS 图片处理
   - 生成多种尺寸缩略图

---

### 成本控制

1. **存储空间优化**
   - 定期清理无用文件
   - 设置生命周期规则
   - 使用低频访问存储

2. **流量控制**
   - 限制单文件大小
   - 限制每日上传次数
   - 监控异常上传行为

3. **防盗链**
   - 配置 Referer 白名单
   - 使用签名 URL
   - 限制 IP 访问

---

### 数据安全

1. **AccessKey 保护**
   - 使用环境变量
   - 不要硬编码
   - 定期轮换密钥

2. **RAM 子账号**
   - 创建专用子账号
   - 最小权限原则
   - 仅授予 OSS 读写权限

3. **HTTPS 传输**
   - 强制使用 HTTPS
   - 防止中间人攻击
   - 加密数据传输

---

### 扩展性

1. **多云支持**
   - 抽象存储接口
   - 支持切换云服务商
   - 兼容 S3 协议

2. **本地存储**
   - 开发环境可使用本地存储
   - 通过配置切换存储后端
   - 降低开发成本

3. **文件元数据**
   - 记录上传者、上传时间
   - 支持文件搜索
   - 便于审计和追溯

## 📝 常见问题

### Q1: 如何处理上传失败？

**A**: 
- 捕获异常并记录日志
- 返回友好的错误消息
- 前端提示用户重试
- 可扩展自动重试机制

### Q2: 如何限制用户上传频率？

**A**: 
- 使用 Redis 记录上传次数
- 限制每分钟/每天的上传数量
- 超出限制返回 429 错误

### Q3: 如何实现图片预览？

**A**: 
- OSS 返回的 URL 可直接访问
- 可使用 OSS 图片处理参数
  ```
  https://bucket.oss.com/image.jpg?x-oss-process=image/resize,w_200
  ```

### Q4: 如何清理过期文件？

**A**: 
- 设置 OSS 生命周期规则
- 或定时任务扫描删除
- 保留最近 N 天的文件

### Q5: 上传头像后数据库未更新怎么办？

**A**: 
- 检查事务是否回滚
- 验证用户 ID 是否正确获取
- 查看日志确认 SQL 执行情况
- 可扩展事务补偿机制
