# 缓存管理功能文档

## 📋 功能概述

本模块提供基于 Redis 的缓存管理功能，包括数据缓存、缓存清除、缓存键管理等。通过合理的缓存策略提升系统性能，减少数据库查询压力，并支持按维度精确清除缓存，保证数据一致性。

## 🔧 技术实现

### 核心技术栈
- **Spring Data Redis** - Redis 客户端
- **Jackson JSON** - 序列化/反序列化
- **Jackson JSR310** - Java 8 日期时间支持
- **CacheService** - 统一缓存服务接口

### 架构设计
```
Service Layer → CacheService → RedisTemplate → Redis Server
                   ↓
            CacheKeyConstants (缓存键常量)
                   ↓
            Cache Clear Strategy (清除策略)
```

## ⚙️ Redis 配置

### application.yaml 配置

```yaml
spring:
  data:
    redis:
      # Redis服务器地址
      host: ${REDIS_HOST:localhost}
      # Redis服务器端口
      port: ${REDIS_PORT:6379}
      # Redis密码
      password: ${REDIS_PASSWORD:123456}
      # 数据库索引
      database: ${REDIS_DATABASE:0}
      # 连接超时时间
      timeout: 3000ms
      # Lettuce连接池配置
      lettuce:
        pool:
          max-active: 8       # 最大活跃连接数
          max-idle: 8         # 最大空闲连接数
          min-idle: 0         # 最小空闲连接数
          max-wait: -1ms      # 获取连接最大等待时间
```

### RedisConfig 配置类

```java
@Configuration
public class RedisConfig {
    
    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory factory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(factory);
        
        // 使用 JSON 序列化器
        template.setValueSerializer(RedisSerializer.json());
        template.setKeySerializer(RedisSerializer.string());
        template.setHashKeySerializer(RedisSerializer.string());
        template.setHashValueSerializer(RedisSerializer.json());
        
        return template;
    }
}
```

**序列化说明**:
- `RedisSerializer.json()` - Spring Data Redis 4.0+ 无参方法
- 自动处理 Java 8 日期时间类型（需 jackson-datatype-jsr310）
- Key 使用 String 序列化，Value 使用 JSON 序列化

## 📊 缓存键设计规范

### CacheKeyConstants 常量定义

```java
public class CacheKeyConstants {
    
    // 动漫列表分页缓存
    public static final String ANIME_PAGE = "anime:page:%d:%d:%s:%d:%d";
    
    // 动漫详情缓存
    public static final String ANIME_DETAIL = "anime:detail:%d:%d";
    
    // 用户追番历史缓存
    public static final String ANIME_USER_HISTORY = "anime:user:history:%d:%s:%d:%d";
    
    // 角色列表分页缓存
    public static final String CHARACTER_PAGE = "character:page:%d:%d:%s:%d";
    
    // 角色详情缓存
    public static final String CHARACTER_DETAIL = "character:detail:%d:%d";
    
    // 轮播图缓存
    public static final String ANIME_BANNERS = "anime:banners:%d";
    
    // 当季新番缓存
    public static final String ANIME_SEASONAL = "anime:seasonal:%d";
}
```

**设计原则**:
1. **层级结构** - 使用冒号分隔不同层级
2. **包含参数** - 缓存键包含所有影响结果的参数
3. **用户维度** - 涉及用户状态的数据包含 userId
4. **统一前缀** - 同类数据使用相同前缀

## 💾 缓存策略

### 1. 动漫列表分页缓存

**缓存键**:
```java
String cacheKey = String.format(CacheKeyConstants.ANIME_PAGE, 
    pageNum, pageSize, titleKey, year != null ? year : 0, 
    userId != null ? userId : 0);
```

**过期时间**: 30 分钟

**清除时机**:
- 爬虫更新动漫数据后
- 用户更新追番状态后（该用户的分页缓存）

**示例**:
```
anime:page:1:10::0:123    // 第1页，每页10条，无标题过滤，无年份过滤，用户123
anime:page:2:10:进击:2013:123  // 第2页，搜索"进击"，2013年，用户123
```

## 🧹 缓存清除策略

### CacheService 核心方法

#### 1. 设置缓存

```java
public void set(String key, Object value, long timeout, TimeUnit unit) {
    redisTemplate.opsForValue().set(key, value, timeout, unit);
}
```

**使用示例**:
```java
cacheService.set(cacheKey, pageInfo, 30, TimeUnit.MINUTES);
```

---

#### 2. 获取缓存

```java
public <T> T get(String key, Class<T> clazz) {
    Object value = redisTemplate.opsForValue().get(key);
    if (value == null) {
        return null;
    }
    return clazz.cast(value);
}
```

**使用示例**:
```java
PageInfo<AnimeSimpleDTO> cached = cacheService.get(cacheKey, PageInfo.class);
```

---

#### 3. 删除单个缓存

```java
public void delete(String key) {
    redisTemplate.delete(key);
}
```

**使用示例**:
```java
cacheService.delete("anime:detail:1:123");
```

---

#### 4. 按模式删除缓存（通配符）

```java
public void deleteByPattern(String pattern) {
    Set<String> keys = redisTemplate.keys(pattern);
    if (keys != null && !keys.isEmpty()) {
        redisTemplate.delete(keys);
    }
}
```

**使用示例**:
```java
// 清除某个动漫的所有详情缓存
cacheService.deleteByPattern("anime:detail:1:*");

// 清除某个用户的所有追番历史缓存
cacheService.deleteByPattern("anime:user:history:123:*");

// 清除所有动漫列表分页缓存
cacheService.deleteByPattern("anime:page:*");
```

**注意事项**:
- `keys()` 操作在大数据量时可能较慢
- 生产环境建议使用 `SCAN` 命令替代
- 避免频繁使用通配符删除

---

#### 5. 清除所有缓存

```java
public Long clearAll() {
    Set<String> keys = redisTemplate.keys("*");
    if (keys != null && !keys.isEmpty()) {
        Long deleted = redisTemplate.delete(keys);
        log.info("清除所有缓存成功: 删除数量={}", deleted);
        return deleted;
    }
    return 0L;
}
```

**使用场景**:
- 开发环境重置
- 紧急情况下清除脏数据
- 测试环境清理

**警告**:
- 这是一个危险操作
- 会清除所有缓存数据
- 建议仅在开发环境或紧急情况下使用
- 生产环境应禁用此接口

## 🔄 缓存更新流程

### 典型缓存使用模式

```java
public PageInfo<AnimeSimpleDTO> getAnimePage(Integer pageNum, Integer pageSize, 
                                              String title, Integer year) {
    // 1. 生成缓存键
    String nameKey = title != null ? title : "";
    Long userId = UserContext.getUserId();
    String cacheKey = String.format("anime:page:%d:%d:%s:%d:%d", 
        pageNum, pageSize, nameKey, year != null ? year : 0, 
        userId != null ? userId : 0);
    
    // 2. 尝试从缓存获取
    @SuppressWarnings("unchecked")
    PageInfo<AnimeSimpleDTO> cached = cacheService.get(cacheKey, PageInfo.class);
    if (cached != null) {
        log.debug("缓存命中: {}", cacheKey);
        return cached;
    }
    
    // 3. 缓存未命中，查询数据库
    log.debug("缓存未命中，查询数据库: {}", cacheKey);
    PageHelper.startPage(pageNum, pageSize);
    List<AnimeSimpleDTO> list = animeMapper.selectAnimePage(title, year, userId);
    PageInfo<AnimeSimpleDTO> pageInfo = new PageInfo<>(list);
    
    // 4. 设置缓存
    cacheService.set(cacheKey, pageInfo, 30, TimeUnit.MINUTES);
    
    return pageInfo;
}
```

---

### 数据更新后的缓存清除

```java
public boolean updateWatchStatus(UserAnimeUpdateRequest request) {
    // 1. 更新数据库
    // ...
    
    // 2. 清除相关缓存
    Long animeId = request.getAnimeId();
    Long userId = UserContext.getUserId();
    
    // 清除动漫详情缓存（所有用户）
    cacheService.deleteByPattern("anime:detail:" + animeId + ":*");
    
    // 清除该用户的追番历史缓存
    cacheService.deleteByPattern("anime:user:history:" + userId + ":*");
    
    // 清除列表分页缓存（该用户的所有分页）
    cacheService.deleteByPattern("anime:page:*:*:*:*:" + userId);
    
    return true;
}
```

## ⚠️ 注意事项

### 缓存一致性

1. **及时清除**
   - 数据更新后立即清除相关缓存
   - 使用通配符删除所有相关缓存
   - 避免脏数据

2. **合理过期**
   - 设置合理的过期时间
   - 热点数据可适当延长
   - 冷数据缩短过期时间

3. **用户维度**
   - 涉及用户状态的数据必须包含 userId
   - 不同用户的缓存要隔离
   - 避免缓存污染

---

### 性能优化

1. **避免缓存穿透**
   - 空值也缓存（短过期时间）
   - 使用布隆过滤器
   - 限流保护

2. **避免缓存雪崩**
   - 过期时间加随机值
   - 热点数据永不过期
   - 多级缓存

3. **避免缓存击穿**
   - 热点数据加互斥锁
   - 异步刷新缓存
   - 预热热点数据

---

### 内存管理

1. **监控内存使用**
   ```bash
   redis-cli info memory
   ```

2. **设置最大内存**
   ```yaml
   maxmemory: 2gb
   maxmemory-policy: allkeys-lru
   ```

3. **定期清理**
   - 清除过期键
   - 清理无用缓存
   - 监控命中率

---

### 序列化问题

1. **Java 8 日期时间**
   - 必须引入 `jackson-datatype-jsr310`
   - 自动注册 `JavaTimeModule`
   - 支持 LocalDateTime, LocalDate 等

2. **泛型类型擦除**
   - 使用 `@SuppressWarnings("unchecked")`
   - 或自定义反序列化器
   - 或使用 TypeReference

3. **循环引用**
   - 避免实体类循环引用
   - 使用 DTO/VO 对象
   - 使用 `@JsonIgnore`

    String cached = cacheService.get(key, String.class);

    cacheService.set("other:key", "value", 5, TimeUnit.MINUTES);
    
    cacheService.deleteByPattern("test:*");
    
    assertNull(cacheService.get("test:key1", String.class));
    assertNull(cacheService.get("test:key2", String.class));
    assertNotNull(cacheService.get("other:key", String.class));

## 📝 常见问题

### Q1: 缓存命中率低怎么办？

**A**: 
- 检查缓存键设计是否合理
- 延长过期时间
- 预热点数据
- 分析访问模式

### Q2: Redis 连接超时怎么办？

**A**: 
- 增加 timeout 配置
- 检查网络连接
- 增加连接池大小
- 监控 Redis 负载

### Q3: 如何监控缓存使用情况？

**A**: 
- 使用 Redis MONITOR 命令
- 集成 Prometheus + Grafana
- 记录缓存命中/未命中日志
- 使用 Redis Insight 工具

### Q4: 分布式环境下缓存一致性问题？

**A**: 
- 使用 Redis Pub/Sub 通知其他节点
- 使用分布式锁
- 缩短缓存过期时间
- 采用最终一致性策略
